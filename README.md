# Harbor Run

An original offline open world crime game set in Sunline County. Drive, explore on foot, take vehicles, evade county patrols, complete three story jobs, and save progress in your browser.

## Run

Serve the `game/` directory with any static file server and open `index.html` in desktop Chrome. For this repository, run `node serve.ts` and visit http://localhost:8080.

WASD moves and steers. Press E near a car to enter or exit. Aim with the mouse and click to fire. Q advances to the next story job. Progress saves automatically in localStorage.

## Story

Courier Mara Vale gets one stormy night to decide who owns a crate uncovered along the coast. Meet Luz at the marina, reach the signal tower, then escape the waterfront patrol.
